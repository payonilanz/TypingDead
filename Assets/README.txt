TYPING DEAD does not load binary art or audio assets.

Every background, enemy, UI panel, particle, projectile, and sound is generated
at runtime with GDI+ and a small PCM synthesizer. This folder is intentionally
empty of media so the project remains self-contained and portable.

Fonts are system fonts (Segoe UI, Consolas, and a small monospace fallback)
selected and cached by TypingDead.UI.UiFonts.
